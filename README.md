# FisioEnCasa App

MVP mobile-first para gestionar la operación diaria de fisioterapia domiciliaria.

## Alcance actual

- Dashboard operativo, pacientes, ficha clínica de demostración y agenda.
- Entrevista guiada física/deportiva y neurológica.
- Progreso funcional y evolución clínica con datos ficticios.
- Sin almacenamiento de datos reales, audio, IA externa, autenticación ni sincronización de calendario.

## Desarrollo local

```bash
npm install
npm run dev
```

## Próximas integraciones

Supabase, autenticación, micrófono/transcripción, OpenAI API y Google Calendar.
